## 🧠 Core Systems & Features

### 🌐 AzahraVerse Web Integration
The bot is fully synchronized with the **AzahraVerse Web Dashboard** in real-time!
* 🪙 **Live Economy:** Instant sync of Coins, Orbs, Cards, and Level XP.
* 🏛️ **Guild System:** Form teams, join guilds, and dominate the global leaderboards directly from WhatsApp.
* 📅 **Rolling Rewards:** Seamless 24-hour reward tracking perfectly aligned with web profiles.

### 🃏 Anime Card Duels & Gacha
Engage in an advanced RNG-based Anime Card Gacha and Battle system!
* ⚔️ **`.duel @user`** — Fair, randomized turn-based combat with dynamic Tier Initiative.
* 🎨 **Stunning SVG Visuals** — Watch HP bars drain with beautiful dark-mode gradient battle cards.
* 🎁 **Auto Card Spawns** — Use `.spawndrop on` to passively drop high-tier cards in large active groups.

### 🤖 Dual-Engine AI Chatbot
Azahrabot features an advanced AI system that remembers your conversations and switches engines seamlessly so it never leaves you hanging.
* 💬 **Smart Memory:** Remembers your last 10 messages for continuous, flowing conversations.
* 🔄 **Fail-Safe Fallback:** Switches between GPT and Gemini if one goes down.
* 🗣️ **Voice Personalities:** Can send human-sounding, expressive Voice Notes on demand.
* 🎨 **AI Image & Video Generation:** Command `.imagine` or `.aivideo` to literally render your imagination.

### 🛡️ Ironclad Group Moderation
Total control over your groups with a single command.
* 🚨 **Anti-Link & Anti-Spam:** Instantly kicks rulebreakers.
* ⚠ **Strike System:** `.warn @user` tracks offenses and auto-kicks at 3 strikes.
* 👑 **Admin Powers:** `.promote`, `.demote`, `.kick`, and `.hidetag` (ghost tags).

## 🚀 Deployment Guide

It only takes 4 simple steps to bring Azahrabot online.

### 📥 1. Clone Repository
```bash
git clone https://github.com/azarudeen011/AzahraBot.git
cd AzahraBot
```

### 📦 2. Install Dependencies
```bash
npm install
```

### ▶️ 3. Start the Engine
```bash
node index.js
```

### 📱 4. Link to WhatsApp
1. A QR Code or Pair Code will appear in the terminal.
2. Open WhatsApp → **Linked Devices** → **Link a Device**.
3. Scan the QR code or enter the Pair Code.
4. 🎉 **Bot is Online!**
